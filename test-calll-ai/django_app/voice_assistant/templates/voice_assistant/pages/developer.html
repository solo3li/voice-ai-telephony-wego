مفتاح الـ API النشط للتطبيقات (Personal Live API Key)

استخدم هذا المفتاح في ترويسة X-API-Key: sk_live_usr_... أو Authorization: Bearer sk_live_usr_... للوصول إلى كافة الموارد.

آخر استخدام: --
استعلام الحساب (Get Account):
curl -X GET "https://localhost/api/v1/account/" \
  -H "X-API-Key: <YOUR_API_KEY>" \
  -H "Accept: application/json"
إجراء مكالمة صادرة بالذكاء الاصطناعي (Dial Call):
curl -X POST "https://localhost/api/v1/calls/dial/" \
  -H "X-API-Key: <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{"phone_number": "+201012345678", "call_goal": "تأكيد تفاصيل الطلب رقم 1005"}'

Zero-Code Embeds
منظومة الكول سنتر والاتصالات المتكاملة المضمنة (Call Center AI Embedded Suite)
10 Sub-Routes Multi-Page

تضمين المنظومة الهاتفية الشاملة بجميع أقسامها العشرة كـ Iframe مدمج أبيض بالكامل (White-Label) خالي تماماً من الفواتير أو أي ارتباط بالمنصة، مع شريط تبويبات علوي متجاوب وتنقل تلقائي مع الحفاظ على التوكن.

معاينة حية للمنظومة
الأقسام الفرعية العشرة المدعومة للتضمين المباشر:

4. استوديو الشخصيات واللهجات /embed/call-center/personas/
5. ذاكرة وسجل العملاء /embed/call-center/crm/
6. متجر أدوات الـ MCP /embed/call-center/tools/
7. حملات الاتصال الصادرة /embed/call-center/campaigns/
8. مركز الاتصال وطوابير الانتظار /embed/call-center/call-center/
9. خطوط SIP وسنترالات PBX /embed/call-center/telephony/
10. مواعيد العمل والخطة البديلة /embed/call-center/hours/
