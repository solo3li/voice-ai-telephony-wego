واجهات المطورين المباشرة (Direct Developer API & Keys)

v1 Active

ادمج المساعد الصوتي والذكاء الاصطناعي وخوادم FastMCP وبدء مكالمات WebRTC مباشرة في موقعك أو تطبيقاتك الخاصة باستخدام مفتاح الـ API الشخصي لحسابك (X-API-Key).

📖 فتح التوثيق التفاعلي (Scalar Docs) ↗
🔑

مفتاح الـ API النشط للتطبيقات (Personal Live API Key)

استخدم هذا المفتاح في ترويسة X-API-Key: sk_live_usr_... أو Authorization: Bearer sk_live_usr_... للوصول إلى كافة الموارد. احرص على حفظه بأمان وعدم مشاركته في الكود المفتوح.

تاريخ الإنشاء: --
آخر استخدام: --
👤 استعلام الحساب (Get Account): 
curl -X GET "https://localhost/api/v1/account/" \
  -H "X-API-Key: <YOUR_API_KEY>" \
  -H "Accept: application/json"
📞 إجراء مكالمة صادرة بالذكاء الاصطناعي (Dial Call): 
curl -X POST "https://localhost/api/v1/calls/dial/" \
  -H "X-API-Key: <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{"phone_number": "+201012345678", "call_goal": "تأكيد تفاصيل الطلب رقم 1005"}'

الذاكرة المنظمة الحية للنشاط (Structured Live Context - In-Memory Cache)

⚪ جاري الفحص... الحجم: 0 KB / 100 KB

بيانات نشاطك الحية والمنظمة (الفروع، مناطق ورسوم التوصيل، المنيو، وقائمة الأصناف غير المتوفرة اليوم). تُحقن فوراً في بداية كل مكالمة من الذاكرة اللحظية (Redis < 2ms) لتمكين الذكاء الاصطناعي من الإجابة بدقة مطلقة دون استدعاء أدوات خارجية أو هلوسة.

آخر تحديث: --
🤖 كيف يقرأ الذكاء الاصطناعي هذا الـ JSON داخل التوجيهات المباشرة (System Instruction): 
جاري التحميل...
💡 كل حفظ جديد يستبدل السابق بالكامل في الـ DB وكاش الـ Redis (Atomic Overwrite).
🔄 تحديث البيانات آلياً من نظام الـ POS / الكاشير / ERP عبر الـ API: 
curl -X PUT "https://localhost/api/v1/context/" \
  -H "X-API-Key: <YOUR_API_KEY>" \
  -H "Content-Type: application/json" \
  -d '{"restaurant_name": "مطعم البرجر الذهبي", "out_of_stock": ["برجر دبل بيف"], "branches": [{"name": "المعادي", "status": "مفتوح", "hours": "12 م - 2 ص"}]}'
👤 1. الحساب والمحفظة GET /account/

استعلم برمجياً عن رصيد محفظتك المتاح، البروفايل الصوتي النشط، وإحصائيات استخدامك.

🎙️ 2. الشخصيات واللهجات /profiles/

إنشاء وتعديل وتفعيل شخصيات الذكاء الاصطناعي واللهجات فورياً.

🧠 3. ذاكرة وسياق العملاء /memory/

استرجاع وتحديث سجل وسياق المتصل التراكمي برقم هاتفه قبل أو أثناء المحادثة.

📚 4. قواعد المعرفة RAG /rag/query/

رفع وفهرسة ملفات PDF ومستندات الشركة والبحث الدلالي بالمتجهات المدمجة مع Gemini.

🛠️ 5. خوادم FastMCP والأدوات /mcp/ & sync/

ربط خوادم الأدوات الخارجية عبر SSE ومزامنة دوال الـ AI للاستدعاء أثناء المكالمات.

⚡ 6. بدء مكالمة WebRTC POST /token/

إصدار توكن LiveKit مؤقت مشفر لبدء مكالمة صوتية حية فائقة السرعة من المتصفح أو التطبيق.

📞 7. السنترالات و DIDs /telephony/

ربط خطوط السنترال الداخلي وأرقام الاستقبال وتوجيه الاتصالات الهاتفية.

👥 8. الموظفون والطوابير /employees/

إدارة تحويلات الموظفين الداخلية وتوزيع المكالمات واستراتيجيات طوابير الانتظار.

📋 9. سجلات المكالمات والويبهوك /calls/ & /webhooks/

استعراض تفاصيل المكالمات، التسجيلات، الملخصات الذكية، واستقبال إشعارات انتهاء المكالمات.

⚡ 10. الذاكرة المنظمة اللحظية /context/

حقن واستبدال فوري لبيانات المطاعم والمنيو والفروع في كاش Redis فائق السرعة (< 2ms) لمنع الهلوسة في المكالمات.
