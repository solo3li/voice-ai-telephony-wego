# بوابة الاتصال الخلوي الذكية (Local GSM USB Dongle AI Voice Gateway)

تطبيق بايثون محلي خفيف وعصري مبني بإطار عمل **Flet (Flutter for Python)** يتيح ربط فلاشات المودم الخلوية (USB Dongles مثل Huawei E173 وغيرها) مباشرة مع منصة الذكاء الاصطناعي الصوتي عبر **LiveKit WebRTC**.

## المميزات الرئيسية
- **دخول المالك المباشر**: تسجيل الدخول باسم المستخدم وكلمة المرور الخاصة بالمالك حصراً (بدون بريد إلكتروني).
- **الدخول التلقائي (Auto-Login)**: تذكر الجلسة محلياً لفتح البوابة مباشرة في المرات القادمة.
- **تصميم البطاقات العصرية (Dynamic Cards)**: هيدر عنابي فاخر (`#680E23`)، بطاقات بيضاء، مؤشرات شبكة 4G وسرعة استجابة السيرفر.
- **خفيف وسريع جداً**: تم استبعاد فقاعات التفريغ النصي اللحظي من الواجهة لضمان صفر استهلاك للمعالج والرام وبدون أي تأخير صوتي.
- **التحكم بالاتصال**: إمكانية كتم الصوت وإنهاء المكالمة بزر واحد.
- **وضع المحاكاة (Simulation Mode)**: زر لتجربة ورود مكالمة واختبار استجابة الذكاء الاصطناعي حتى بدون وجود فلاشة مادية متصلة.

## طريقة التثبيت والتشغيل

### 1. تثبيت المتطلبات:
```bash
pip install -r requirements.txt
```

### 2. تشغيل التطبيق:
```bash
python main.py
```
